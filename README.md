# studyforge-apps

StudyForge 英文練功房 — a small collection of static English-grammar practice
web apps (Traditional Chinese UI, aimed at junior-high verb tenses).

**Live:** https://studyforge-apps.vercel.app

## Apps

- `index.html` — hub page linking the apps below
- `verbs3.html` — irregular verb three-forms drill (不規則動詞三態)
- `evolution.html` — verb-forms "evolution dex" (三態進化圖鑑)
- `tensehunt.html` — verb tense hunter quiz (動詞時態獵人)
- `tensestory.html` — short-passage tense challenge (短文時態挑戰)
- `patterndig.html` — pattern archaeology game (規律考古學家)

## Run

Pure static HTML — no build step. Open any page in a browser, or serve the
folder with `python3 -m http.server`.
